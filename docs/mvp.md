# 历史：单一用量桌宠需求草案

此文保留前期讨论。当前范围已扩展为 PC 助手，以 [当前验收要求](pc-assistant-acceptance.md) 和 [README](../README.md) 为准。

更新日期：2026-10-09

## 已确认需求

1. 支持不同 AI Agent 之间切换；只展示当前选中的 Agent。
2. 每个 Agent 可配置独立形象和动画资源；切换 Agent 时同步切换形象。
3. Codex 默认使用用户指定的 ChatGPT 民间形象，具体版本待确认。
4. 先研究并复用现有桌宠，只有明确缺失的能力才自行开发。

## 核心体验

- 桌面仅保留一个可拖动的宠物，通过右键菜单或面板选择当前 Agent。
- 点击宠物展开当前 Agent 的用量面板，显示名称、可用的额度指标、统计窗口、重置时间及更新时间。
- Agent 切换后，宠物、用量、刷新和提醒对象一起切换，并记住最近选择。
- 无可用数据时显示“未连接”“暂不可用”或“数据已过期”，不能将缺失数据当作额度充足。
- 提供手动刷新；自动刷新频率依据数据源能力确定。
- 首版提醒仅面向当前 Agent，阈值可配置；重新切换时不重复触发同一提醒。

## 自定义动画

- 设置中可为每个 Agent 选择、导入和替换资源包，保存 Agent 与角色之间的对应关系。
- 资源包包含角色名称、作者与来源信息、预览和状态动画。
- 优先兼容所选底座已有的 GIF 或精灵图资源包格式；选定底座前不另造完整格式。
- 建议支持待机、低额度、额度耗尽、数据不可用等状态；工作动画只在数据源能报告活动时启用。
- 某状态缺少动画时回退到待机；一个待机动画也能成为可用形象。
- 切换形象不改变 Agent 的账户与数据源设置。
- Codex 形象候选：ChatGPT 白发龙娘；目前只是候选，尚未下载或内置。

## 桌面交互

- 暂按 Windows 规划，支持拖动、置顶开关及位置记忆。
- 支持面板收起、托盘入口和明确的退出操作。
- 低额度状态可使用动画或小标记表达，仍提供准确数值。

## 数据接入原则

- Agent 的活动状态、Token 消耗和账户订阅额度是不同数据，分别标识。
- 数据获取与宠物皮肤分离，优先复用已验证的适配器。
- 同一时刻仅显示当前 Agent，不把多个平台的额度相加。
- 订阅额度、Token 用量、请求次数和 API 花费分别呈现。
- 显示数据来源、更新时间和有效状态，不以估算值冒充真实额度。
- 当前聊天工具的能力不等于独立桌面应用可调用的接口，接入方式需独立验证。
- 不将密钥或登录凭据写入源码或日志。

## 验收条件

- Agent A 与 B 之间切换后，桌面始终只有一个宠物，名称、数据和形象与选择一致。
- 每个 Agent 的皮肤设置和最后选中的 Agent 在重启后保留。
- 用户可导入至少一套自定义动画，替换后无需重新编译程序。
- 缺少状态动画时正常回退；不可用的数据明确标注。
- 至少接通一个真实用量数据源，显示更新时间并核对源数据。
- 退出后没有本应用残留后台进程。

## 待确定

- 首批接入的其他 Agent 名单。
- 用户所指的 ChatGPT 民间形象具体版本。
- 数据侧最关注订阅剩余额度、Token 用量还是 API 费用。
- 现有底座能否直接完成单 Agent 展示及 Agent 与角色绑定。

## 实施顺序

1. 对照需求评估 AgentPaw 和 Clawd on Desk；优先直接使用。
2. 试用验证当前 Agent 切换、真实额度与自定义资源导入。
3. 若确有差异，基于选定底座增加单 Agent 展示和角色绑定。
4. 确认形象后复用或制作动画，再扩展其他 Agent。
