## 数据与边界

旧数据自动迁移到带关联关系的日程结构，保留原 JSON 备份机制。新版可执行文件在独立分发目录，原版产物保留。测试均使用隔离数据目录。

该版本不会自动升级 Agent、消耗重置卡或上传便签/Git 内容。翻译通过外部网页服务，需要能访问 Google Translate；可以随时打开官方原文。精确到秒指存储和输入精度，通知可能受系统负载、休止和免打扰影响。未验证其他机器、超大型仓库和全部时区配置。
