# DeskMate 0.6.0 Rust 迁移验收

验证日期：2026-10-28。平台：Windows x64；Rust 1.99.1 / Tauri 2.12.5；保留原 HTML/CSS/JavaScript 界面和 SQLite version 1 数据结构。

## 已通过

- `npm.cmd test`：13 项 Rust 集成测试，包括 SQLite 与原 Node 存储层双向兼容、JSON 导入与回滚、备份恢复、未来结构版本保护、提醒与重启、真实 Git 仓库及删除分支历史、查询分页、Unicode、用量字段、Codex stdio、动画导入路径限制、负坐标与缩放、Rust 状态行。
- `npm.cmd run check`：全部目标的 clippy 检查通过，警告视为错误。
- `npm.cmd run test:ui`：开发版与最终正式免安装版均通过。覆盖旧 JSON 导入、额度与 Token、8 个角色的 WebP 解码、三语、便签、提醒暂停和推迟、Git 作者/内容筛选、形象绑定、额度条键盘展开/收起、窗口权限限制和重启持久化。
- 免安装目录中 74 个素材文件逐一与源码 SHA-256 比对一致。
- 正式版 `--claude-statusline` 从标准输入读取测试额度，输出 `5h: 0%`，只保存规范化额度，不保存输入中的其他字段，也不创建桌面数据库或打开窗口。
- NSIS 安装包生成成功；只读检查其归档包含 8 套素材、EXE、迁移说明与数据库说明，不包含测试 Codex 替身。
- 所有业务测试使用隔离数据目录，未转换当前用户正在使用的数据。

## 产物

- `release/DeskMate-0.6.0-rust-win32-x64/`：完整免安装目录，EXE 大小 9,321,984 字节。整个目录一起保留。
- `src-tauri/target/release/bundle/nsis/DeskMate_0.6.0_x64-setup.exe`：安装包，14,138,575 字节。
- `test-output/rust/`：实际 Tauri/WebView2 运行时的界面截图。

## 尚未完成的手动验收

原生工具已观察到桌宠透明窗口；实鼠标检查受到用户输入中断，长按拖动及透明区域点击穿透尚未完成手动验收。自动测试的键盘额度条检查和坐标边界测试不能替代这两项实鼠标验收。未在另一台 Windows 电脑上安装运行。

首次使用前通过旧版托盘退出旧程序，再启动新版。新版会沿用现有 SQLite，或事务导入旧 JSON，并保留迁移前文件。详细构建、数据与回退边界见 [Rust 迁移说明](rust-migration.md)。
