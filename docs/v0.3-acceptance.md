# DeskMate v0.3.0 验收（2026-10-10）

## 本次调整

- 通用名称为 **DeskMate / 桌伴 / デスクメイト**，项目目录已从 `agent-usage-pet` 改为 `deskmate`。应用标题、托盘、可执行文件、包名、图标、三语 README 和构建命令已同步。
- 桌宠显示当前 Agent 的 5 小时与长期额度窗口，不再显示重置卡；用量面板继续显示重置卡数量和到期详情。
- 新用户数据目录为 `%APPDATA%/DeskMate`。存在旧版数据且新目录没有数据时继续使用 `%APPDATA%/Longling PC Assistant`，保留便签、提醒、设置和自定义动画；旧环境变量仍兼容。
- 新增 `npm.cmd run dist`，从当前源码生成 Windows x64 NSIS 安装程序。安装向导提供中文、英语、日语，支持目录选择、桌面及开始菜单快捷方式，卸载保留数据。构建不会发布到外部服务。

## 验证结果

- 功能测试：14 项通过，包括重命名后的数据目录兼容性。
- 免安装版及实际安装后的界面流程均通过：三语切换与重启持久化、菜单及弹窗、草稿保护、秒级便签及提醒、Git 本地作者筛选、日志翻译链接、自定义动画、后台提醒。
- 隔离样本验证：桌宠只有 5 小时及长期额度两行，没有重置卡；主面板仍显示 2 张重置卡和 Token 统计。

- 安装版与已验证免安装版的 `app.asar` SHA-256 一致。
- 使用安装版自带卸载程序完成卸载，退出码为 0；安装目录和卸载项被清除，既有用户数据文件哈希未变，原快捷方式已恢复。
