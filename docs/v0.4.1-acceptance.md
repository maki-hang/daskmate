# DeskMate v0.4.1 验收（2026-10-12）

- 悬停与持续显示共用同一套条形样式，宽度统一为 180 像素，保留各窗口末尾的剩余额度进度条。两种模式仅显示时机不同。
- 移除桌宠右上角拖动柄。在宠物身上按住左键约 350 毫秒后移动即可拖动，松开停止并保存位置。拖动后、原地长按后或 Esc 取消后都不会触发打开界面。
- 短按左键继续打开主界面；右键菜单和额度条点击入口保持可用。拖动过程中固定接收鼠标事件，结束后恢复透明区域的点击穿透。
- 使用 Electron 的屏幕 DIP 坐标移动原生窗口，并约束在目标显示器工作区内。失去焦点、隐藏、指针捕获取消及退出时结束拖动。新增交互说明与 README 均提供中文、英语、日语。
