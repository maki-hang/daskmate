# デスクメイト · PC アシスタント

[中文](README.md) · [English](README.en.md) · **日本語**

AI 使用量、Git 履歴、メモ、リマインダーをまとめた Windows x64 用デスクトップペットです。表示する Agent はひとつ。Agent ごとに別のアニメーションを設定できます。

## 起動

`release/DeskMate-0.4.1-win32-x64/DeskMate.exe` を実行してください。フォルダー内のファイルは一緒に保管してください。旧版が起動中の場合は、先にトレイの「デスクメイトを終了」を選びます。データフォルダーは共通で、既存のメモと通知は自動移行されます。

ソースから実行する場合は Node.js 22.12+、npm、Git が必要です。

```powershell
npm.cmd ci
npm.cmd start
```

ペットをクリックしてパネルを開きます。右クリックまたはトレイで Agent を切り替え、ペット上で左ボタンを約 350 ミリ秒長押ししてから動かすとドラッグできます。離すと位置を保存し、パネルは開きません。短い左クリックでは引き続きパネルを開きます。パネルを閉じても常駐し、トレイから終了できます。

## ペットの残量表示

「外観と設定 → ペットの残量表示」、またはペットの右クリックメニューで選択できます。

- **常に表示**（初期設定）：幅 180 ピクセルのコンパクトなバーに、各期間の残量とプログレスバーを表示。残量が少ない場合は暖色で示します。
- **ホバーで表示**：ペットにカーソルを合わせると、常時表示と同じ幅 180 ピクセルのバーを表示します。バーへ移動してクリックすると使用量パネルが開き、離すと自動で閉じます。キーボードのフォーカスでも表示でき、Esc で閉じます。

設定はすぐに反映され、再起動後も保持されます。どちらのモードも 5 時間の期間を優先し、リセット枚数は使用量パネルだけに表示します。非表示のカードと透明な余白はクリックを透過します。

## 言語

右上または設定で中国語・英語・日本語を選択できます。画面、ペット、トレイ、日時、説明書に適用され、次回起動時も保持されます。初回はシステム言語に合わせ、対象外の言語では中国語を使用します。ユーザーのメモ、コミット内容、追加した素材の名前は翻訳しません。

## 使用量と更新

- **Codex**：公式ローカル `app-server` の `account/rateLimits/read` と `account/usage/read` を使用。既存のログインを利用し、使用量の取得でモデルのタスクを開始しません。返された 5 時間・7 日などの期間を個別表示し、次回リセット、獲得したリセットの枚数と有効期限、今日と累計のトークンを表示します。欠損データは 0 ではなく `—` です。リセットは表示のみで、利用は Codex から行ってください。詳細が省略・制限されても枚数はサーバーの値を使用します。日別集計はサービス側の日付に従い、該当日のデータがなければ不明と表示します。
- **Claude Code**：ローカルログの入力・出力・キャッシュトークンを集計し、ストリーミングやコピーによる重複を除きます。任意のステータスライン連携で 5 時間・7 日の残量も表示できます。10 分以上経過、またはリセット時刻を過ぎたスナップショットには古い旨を表示します。Codex のアカウント集計とは対象範囲が異なります。
- **ペット**：5 時間の残量を長期間の残量より先に表示し、リセット枚数はメインの使用量パネルのみに表示します。残量にマウスを重ねるとリセット日時を確認できます。行が多い場合はスクロールできます。
- **Agent の更新**：公式 GitHub の **Codex CLI / Claude Code** 安定版を 6 時間ごとに確認し、検出できたローカル CLI のバージョンと比較します。検出できなければ不明と表示します。Codex デスクトップアプリの更新機能ではなく、自動インストールや自動更新も行いません。
- **更新履歴**：中国語・日本語では該当する公式リリースを Google のウェブ翻訳で開き、英語では原文を開きます。公式原文へのボタンもあります。Google 翻訳への接続が必要で、翻訳の誤りや利用不可の場合もあります。Google に渡すのは公開リリース URL のみで、メモや Git 履歴は送信しません。取得済みのリリースはキャッシュされ、再取得に失敗すると古い情報である旨を表示します。

出典：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、[Claude ステータスライン](https://code.claude.com/docs/en/statusline)、[Codex CLI リリース](https://github.com/openai/codex/releases)、[Claude Code リリース](https://github.com/anthropics/claude-code/releases)。

## Git 履歴

リポジトリを追加するかフォルダーを検索します。ローカルの全ブランチ、取得済みのリモート追跡ブランチ、reflog から到達可能なコミットを毎分収録します。収録済みの履歴はブランチ削除後も保持します。内容・作成者・メール・ハッシュの検索、リポジトリ・日付の絞り込み、ページ送りが可能です。

既定では「ローカルの作成者のみ」を表示します。各リポジトリで有効な `git config user.email` を使い、メール未設定時は `user.name` で照合します。両方未設定の場合は該当なしになります。「すべての作成者」に切り替えるか Git を設定してください。リポジトリごとの設定を尊重し、絞り込みによって記録を削除することはありません。手動同期ボタンはありません。Git の設定や Hook の変更、fetch/push は行いません。未取得・未登録の履歴や、未収録のまま回収されたコミットは復元できません。

## メモとリマインダー

統合したカレンダーで、1 日に複数のメモを **日付・時・分・秒** まで指定できます。メモに一度のみ・毎日・毎週の通知を付けられます。編集、一時停止、再開、10 分後に再通知、既読化、メモと通知の一括削除に対応します。選択日・すべてのメモ・未読通知で絞り込めます。繰り返しや再通知のあるメモは次回通知日にもとづいてカレンダーに表示され、元のメモの日付も保持します。

PC のローカルタイムゾーンを使用します。常駐中はパネルを閉じてもシステム通知とペットの吹き出しで知らせます。電源が切れた PC は起こしません。終了・休止中の通知は起動・復帰時に一度表示し、繰り返しの予定は未来へ進めます。集中モードなどで OS 通知が抑制されても未読一覧と吹き出しは残ります。秒単位で指定できますが、リアルタイム保証はなく、休止や負荷で遅れる場合があります。本文のみの編集では完了・一時停止を保持し、日時・繰り返しを変更すると再設定します。パッケージ版ではログイン時の起動も設定できます。

旧版の日付のみのメモには `00:00:00` を付与し、既存の通知は状態と繰り返しを保持した関連メモへ移行します。言語変更時も入力途中の内容を保持し、画面移動で破棄する前に確認します。

## アニメーション

Agent を選択し、設定でローカルの `skin.json` を読み込みます。

```json
{
  "name": "私の相棒",
  "author": "作者名",
  "source": "素材の出典",
  "license": "利用条件",
  "states": {
    "idle": "idle.webp",
    "happy": "happy.gif",
    "attention": "attention.webp",
    "reminder": "reminder.webp"
  }
}
```

必須は `idle` のみ。`error`、`working` も使用できます。GIF/WebP/PNG/APNG は素材フォルダー内に置き、1 ファイル 20 MB 以下にしてください。読み込み時にコピーし、不足する状態は待機表示で代用します。Codex のスプライト ZIP は直接読み込めません。

## Claude の残量連携（任意）

Node.js を用意し、Claude Code 設定に次を追加します。パスは環境に合わせて変更してください。既存のステータスラインがある場合は上書きせず、スクリプトを連結してください。

```json
{
  "statusLine": {
    "type": "command",
    "command": "node \"E:/brain-storming/deskmate/scripts/claude-statusline.cjs\""
  }
}
```

パッケージ版では `resources/claude-statusline.cjs` です。残量・リセット時刻・更新時刻のみ保存してステータスラインを出力し、認証情報の読み取りや追加の残量リクエストは行いません。双方で同じデータフォルダーを使用し、古いスナップショットは Claude を再使用して更新してください。

## Windows インストーラーの作成

`E:\brain-storming\deskmate` で PowerShell を開きます。Windows x64、Node.js 22.12+、npm が必要です。初回は Electron と NSIS ツールをダウンロードします。

```powershell
npm.cmd ci
npm.cmd run dist
```

出力は `release/installers/DeskMate-Setup-0.4.1-x64.exe`。`dist` は毎回現在のソースから作成するため、先に `package` を実行する必要はありません。中国語・英語・日本語に対応し、管理者権限不要のユーザー単位インストール、インストール先の選択、デスクトップとスタートメニューのショートカット作成が可能です。完了後に自動起動しません。Windows の「インストールされているアプリ」からアンインストールでき、ユーザーデータは保持されます。同じバージョンを再ビルドすると、そのインストーラーを更新します。

ポータブル版のみ必要な場合は `npm.cmd run package` を実行します。出力先は `release/DeskMate-0.4.1-win32-x64/`。既存の出力先は上書きせず、再作成には別の `DESKMATE_BUILD_NAME` を指定できます。両版はデータを共有するため、切り替える前に起動中の版を終了してください。

設定は `electron-builder.cjs`、処理は `scripts/installer.cjs`、オリジナルのアイコン生成は `scripts/icon.cjs`。バージョンは `package.json` に従います。electron-builder の NSIS を使用し、自動公開はしません。未署名のため Windows に不明な発行元と表示される場合があります。公開配布の前に署名を別途設定できます。既定素材の CC BY-NC 4.0 非商用条件はインストーラーにも適用されます。

## データ・開発・検証

新規ユーザーの保存先は `%APPDATA%/DeskMate/`。新しいフォルダーにデータがなく、旧版の `%APPDATA%/Longling PC Assistant/assistant.json` が存在する場合は、移動・削除せず旧フォルダーを引き続き使用します。`DESKMATE_DATA_DIR` を優先し、旧変数 `LONGLING_DATA_DIR` も利用できます。`assistant.json` はメモ・通知・設定、`.bak` は直前の復元用コピーです。`git-*.json` はコミット索引、`skins/` は追加素材、`release-*.json` は更新情報です。バックアップは終了後にフォルダー全体をコピーします。`DESKMATE_DATA_DIR` で保存先を分離できます。

```powershell
npm.cmd test
npm.cmd run test:ui
npm.cmd run test:pet    # ペット表示・操作・設定の保持
npm.cmd run package
```

公式 Electron ランタイムと ASAR で配布し、既存の出力先は上書きしません。署名なしの Windows x64 ポータブル版です。画面はサンドボックス・コンテキスト分離・制限付き IPC を使用します。通知は重複防止のため先に保存し、直後にクラッシュした場合は未読一覧から確認できます。メモと Git 履歴はアップロードしません。

`src/` はアプリ、`assets/` は素材とライセンス、`scripts/` はビルド・連携、`test/` は検証です。過去の調査は `docs/existing-projects.md` にあります。他の Windows PC、大規模リポジトリ、すべての時差・通知設定は検証していません。
